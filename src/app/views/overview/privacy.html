Privacy Policy

How Cyrus handles your data — last updated November 2026

Your data never leaves your device. Cyrus is a fully local application. No information you enter, generate, or store within this app is ever transmitted to, collected by, or stored on any server controlled by the developers of this software. The one exception is optional and off by default: if you turn on anonymous usage stats, Cyrus sends a small check-in that contains none of that information (see below).

Data Stored Locally

Local Only

The following information is written to a SQLite database that lives entirely on your machine. Nothing listed here is sent anywhere.

  • Account credentials — your username and a bcrypt-hashed copy of your password. Your plaintext password is never stored.
  • Exchange API keys — your connect API key and secret. These are encrypted again inside the encrypted database and decrypted only when Cyrus needs to contact your exchange.
  • Exchange connections — the name, label, and status of each exchange account you add.
  • Automation rules — trigger conditions, action parameters, and execution logs for any custom commands you create.
  • Session tokens — short-lived JWT tokens kept in memory for the duration of your session; they are not persisted to disk.

The whole database is encrypted (SQLCipher, AES-256). Its key is unique to your install and protected by Windows or macOS for your user account, so a copy of the file is unreadable on another computer or account — including to anyone who copies it from your PC.

Database location: %APPDATA%\Cyrus\kraking.db on Windows, ~/Library/Application Support/Cyrus/kraking.db on macOS

Local-Only Backend

Localhost

Cyrus runs a lightweight Flask server bound exclusively to 127.0.0.1 (your machine's loopback address). This server is started automatically when you open the app and terminates when you close it. It is not accessible from the internet, your local network, or any other device — only the Electron window running on your machine can communicate with it.

Network Communications

Complete List

These are the only services Cyrus talks to over the internet. The last three happen only if you turn them on.

  • Your exchanges — when you load balances, orders or transfers, validate an API key, or an automation rule runs. These calls go directly to the exchange's official API using your own keys; the Cyrus developers receive no copy of them or their responses.
  • CoinGecko — coin fundamentals (market cap, supply, all-time highs) on the Holdings page. Only coin names such as "bitcoin" are sent; never balances, amounts or account details.
  • GitHub — checks whether a newer version of Cyrus has been released, and downloads it if you choose to update. The check carries nothing about you.
  • Cloudflare's public CDN — loads the icon font when the app opens.
  • Anthropic — only if you add your own API key for the AI assistant: your question and a summary of your portfolio, billed to your Anthropic account.
  • Your email provider — only if you turn on email notifications or the monthly report, through the mail server you set up in Profile.
  • Cyrus usage stats — only if you opt in. Anonymous check-ins, described below.

API Key Security

Encrypted at Rest

Exchange API keys are sensitive credentials. Cyrus handles them with the following protections:

  • Keys are encrypted (Fernet: AES with an HMAC) before being written to the database, which is itself encrypted with AES-256 using a key only your user account on this computer can unlock.
  • Keys are decrypted in memory only at the moment a request to your exchange is made, then discarded.
  • Keys are never logged, displayed in plaintext after submission, or transmitted to any party other than your chosen exchange.
  • It is strongly recommended to create API keys with the minimum required permissions (read-only) and to restrict them to your IP address in your exchange's API settings.

Anonymous Usage Stats (Optional)

Off Unless You Opt In

After you first sign in, Cyrus asks whether you'd like to share anonymous usage stats. Nothing is sent unless you say yes, and you can change your answer any time in Profile → Account. If you opt in, Cyrus sends a small check-in when it starts, when you sign in or out, every five minutes while it's running, and when it quits. Each check-in contains only:

  • A random install ID — created on this device when you opt in. It isn't derived from your account, hardware or anything else, and it's discarded when you opt out, so a later opt-in can't be linked to the earlier one.
  • The Cyrus version and your operating system and processor type (e.g. Windows x64, macOS arm64).
  • Whether the window is open or Cyrus is running in the tray, and whether someone is signed in.
  • What prompted it — start, sign-in, sign-out, routine check-in, or quit.
  • Your country — not sent by Cyrus, but looked up by the server from the connection the check-in arrives on (e.g. "United States"). Only the country is kept: never your region, city, or IP address. If you use a VPN, it records the VPN's country.

It never includes your username, email address, balances, holdings, exchanges, API keys, orders, automation rules, or anything else you enter into Cyrus. The check-ins go to a small server run by the Cyrus developer on Cloudflare. That server can see your IP address in order to reply, to limit abuse, and to look up your country, but does not store it. Records are deleted automatically 90 days after an install was last seen, and turning the setting off deletes them immediately.

Cyrus does not include any of the following, whether or not you opt in:

  • Event tracking of what you do inside the app
  • Crash reporting or error telemetry sent to external services
  • Advertising identifiers or fingerprinting
  • Syncing of your data to any server
  • Third-party SDKs that collect or transmit personal information

Your Control

Full Control

Because all data is local, you are always in complete control:

  • Delete a connection — removes that exchange's API keys from the database immediately via the Profile page.
  • Delete all data — uninstalling the application and deleting %APPDATA%\Cyrus (Windows) or ~/Library/Application Support/Cyrus (macOS) removes everything permanently.
  • Offline use — your account, rules and history are stored locally and stay available without an internet connection; only the services listed above need one.
