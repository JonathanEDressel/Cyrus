## Fix: the Cyrus icon on Windows

On Windows, the Desktop and Start Menu shortcuts, the taskbar and the installed program showed Electron's default icon instead of Cyrus's. Task Manager also listed the app as "Electron". Both now say Cyrus.

If a shortcut still shows the old icon after updating, Windows is showing a cached copy. It catches up after a restart, or you can delete the shortcut and open Cyrus from the Start Menu.

**Updating from 1.3.0 on Windows:** use **Update now** in the window Cyrus shows, or the **Update** button in the top bar. It's the first update that installs from inside the app.

**Upgrading from an earlier version:** install over your existing version. Your database, settings, exchange connections and automation rules are kept.
